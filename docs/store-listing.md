# Chrome Web Store Listing - WhatsApp ReplyPal

## Extension Title
WhatsApp ReplyPal

## Short Description (132 characters max)
Quickly view and reply to WhatsApp Web messages from a compact popup. Combines recent messages and auto-refreshes every 5 seconds.

## Detailed Description

### Overview
WhatsApp ReplyPal is a lightweight Chrome extension that enhances your WhatsApp Web experience. View your latest messages in a compact popup and reply instantly without switching tabs.

### Key Features
📱 **Latest Message Display**: Shows the most recent message(s) from your active WhatsApp Web chat

🔄 **Message Concatenation**: Combines consecutive messages from the same sender within 2 minutes

⚡ **Auto-refresh**: Updates messages every 5 seconds when popup is open

💬 **Direct Reply**: Send replies without leaving your current tab

📊 **Reply Counter**: Tracks how many times you've replied in the current conversation

🎯 **Smart Detection**: Only works when WhatsApp Web is open and active

🎨 **Clean Interface**: WhatsApp-inspired design with glassmorphism effects

🌍 **RTL/LTR Support**: Automatically detects and displays Arabic, Hebrew, and other RTL languages correctly

😊 **Emoji Picker**: Built-in emoji keyboard with quick access to popular emojis

⌨️ **Keyboard Shortcuts**: Enter to send, Shift+Enter for new lines

📅 **Relative Dates**: Shows "Today", "Yesterday", or formatted dates for messages

### How It Works
1. **Open WhatsApp Web** in a Chrome tab and select a chat
2. **Click the extension icon** in your browser toolbar
3. **View the latest message(s)** from your active conversation (with sender info and timestamp)
4. **See your reply count** for the current conversation
5. **Type and send replies** directly from the popup using the text area
6. **Use emojis** via the built-in emoji picker
7. **Messages auto-refresh** every 5 seconds while popup is open

### Privacy & Security
🔒 **Local Processing**: All message extraction happens locally in your browser
🚫 **No Data Storage**: Messages are never stored or transmitted externally
🎯 **Minimal Permissions**: Only accesses WhatsApp Web pages with your explicit permission
🔐 **Secure**: Uses Chrome's secure extension APIs

### Perfect For
- **Multitaskers** who need quick WhatsApp access without tab switching
- **Business users** monitoring customer messages while working
- **Anyone** wanting to stay connected without disrupting workflow
- **Multilingual users** who communicate in RTL languages (Arabic, Hebrew, etc.)

### Requirements & Limitations
- **WhatsApp Web must be open** in a Chrome tab
- **Active chat required** - shows messages from your currently selected conversation
- **Local processing only** - no data is stored or transmitted externally
- **Chrome 88+ required** for Manifest V3 compatibility

### Technical Details
- **Manifest V3** compatible
- **Chrome 88+** required
- **Works with all Chromium-based browsers**
- **Lightweight** - minimal impact on browser performance
